# Geografía del mapa de cobertura

`spain-provinces.json` contiene los contornos de las 52 provincias/ciudades autónomas, simplificados y proyectados para el mapa ilustrativo del pie. Se conservan Península, Baleares, Ceuta y Melilla; Canarias se muestra en un recuadro desplazado. Las 11 provincias enlazadas se seleccionan por su código provincial, nunca por un contorno dibujado a mano.

Fuente: [CartoDB Common Data / Click That Hood](https://github.com/codeforgermany/click_that_hood/blob/main/public/data/spain-provinces.geojson). Blob original: `adb0c138f3d0b32afbc5a9bc5799f9f42040b26a`. Metadatos originales: `spain-provinces.metadata.json`, del mismo repositorio. Simplificación Douglas-Peucker de 0,018 grados; proyección equirectangular con corrección por latitud. Uso ilustrativo, no cartografía de precisión.

El recurso se incluye localmente y no depende de un servidor de mapas en producción.
